# ✈️ Recomendação de Roteiros

> Recomendação personalizada de destinos e roteiros com IA. Sugere a viagem ideal por perfil, orçamento e interesses, aumentando conversão e satisfação do viajante.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/turismo-recomendacao-roteiros/

[![Setor](https://img.shields.io/badge/Setor-Turismo-blue)]() [![IA](https://img.shields.io/badge/IA-Neural%20Networks-green)]() [![Demo](https://img.shields.io/badge/Demo-Interativa-orange)]() [![Dados](https://img.shields.io/badge/Dados-CSV%2FExcel-success)]()

## 📊 Resultados-chave (KPIs)
**+36%** Conversão · **+24%** Satisfação · **1:1** Personaliz. · **milhares** Destinos

## 🧠 Tecnologias de IA
Neural Networks · Recommendation · NLP

## ✨ O que faz
- Roteiro personalizado
- Match perfil x destino
- Otimização de orçamento
- Descoberta de destinos
- Jornada do viajante

## 🗄️ Fonte de dados real
[Embratur + avaliações](https://www.gov.br/turismo) — bases de entrada e resultados disponíveis para download em CSV/Excel no app.
